# 每日热点筛选 · 工作台

面向抖音/小红书/快手/视频号多平台的**热点选题筛选工作台**。按固定四步流程（去重排序 → 适配判定 → 素材产出 → 内容池），支持**账号分类**与**渠道**双维度切换，输出可直接复制的中英文候选推文，并支持人工审核与「偏好进化」。

> 数据全部来自公开渠道实时抓取，**禁止编造**；缺失精确热度的条目以「在榜/声量飙升」标注，不杜撰数字。

---

## 一、功能

- **① 账号分类切换**：美食 / 摄影 / 情绪 / 穿搭 / 旅行 / 知识 / 美妆 / 萌宠 / 健身 / 搞笑 / 影视 / 音乐 / 母婴 / 家居 / 数码（共 15 个热门分类）。切换后「适配判定」与候选推文调性按该垂直重算。
- **② 渠道切换**：综合 / 抖音 / 小红书 / 快手 / 视频号。切换后**只显示该渠道来源**的热点（选「综合」= 聚合/媒体报道）。
- 两过滤器组合筛选；统计卡、总览表、内容池随选择实时更新。
- **待审核内容池**：每条含事件摘要、来源、切入角度、中文/英文候选推文（一键复制），以及 `采纳 / 驳回 + 备注` 审核。
- **偏好进化**：驳回记录持久化；「每日热点筛选」自动化次日据此对同类热点降权。
- **导出**：一键导出含审核标记的 Markdown；可将驳回偏好导出为 `rejected-log.json` 供自动化消费。

## 三、本地预览

直接双击 `index.html` 即可查看（分类/渠道/审核均正常）。若需「偏好 JSON 同步」（`rejected-log.json` 自动合并）功能，建议起一个本地静态服务器（浏览器对 `file://` 的 `fetch` 有限制）：

```bash
# 任选其一，在项目根目录执行
python -m http.server 8080
# 或
npx serve .
```

然后访问 `http://localhost:8080/`。

## 四、线上部署（GitHub Pages）

本工作台是零依赖静态站点，可直接部署到 GitHub Pages。

1. 将本项目推送到一个 GitHub 仓库（公开仓库可免费使用 Pages）：
   ```bash
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
   git push -u origin main
   ```
2. 在仓库 **Settings → Pages** 中，Source 选择 **Deploy from a branch**，Branch 选 **main** / 目录 **/ (root)**，保存。
3. 等待 1–2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。

> 也可使用 CloudStudio / Vercel / Netlify 等静态托管，上传根目录即可，无需构建。

## 五、每日自动更新

「每日热点筛选」定时任务（WorkBuddy 自动化）会：
1. 每日定时抓取各渠道当日真实热点，跑四步流程；
2. 读取仓库内 `rejected-log.json` 的历史驳回，对同类热点**降权/默认判不适合**；
3. 用新数据**重写 `data.js`**（覆盖 `HOTSPOT_DATA` 与 `DATA_DATE`）；
4. 若仓库已配置远程且凭证可用，自动 `commit` + `push`，Pages 随即更新；
5. 推送一份筛选摘要。

**人工审核 → 自动化降权 的闭环**：
- 在工作台「偏好进化」面板点「⬇ 导出偏好 JSON」下载 `rejected-log.json`；
- 提交到仓库（`git add rejected-log.json && git commit && git push`）；
- 次日自动化即据此调整筛选偏好。

## 六、数据字段说明（data.js）

```js
{
  id: "C01",                       // 唯一编号
  title: "热点标题",
  channels: ["抖音","小红书"],     // 实际走红平台；[] 表示仅综合/媒体报道
  cats: ["美食","知识"],           // 天然相关的垂直分类
  source: "信息来源",
  heat: "热度描述",
  heatNum: 1048,                  // 热度数值（万），无精确值则 null
  summary: "事件摘要",
  hook / hookEn: "切入钩子",
  caution: "注意事项（可选）",
  drafts: { 分类: { angle, cn, en } }  // 手工/优选候选推文（可选，缺省按模板生成）
}
```
